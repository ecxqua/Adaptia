### 📐 Принципы, которые закрыты архитектурой

| Принцип | Где видно |
|:---|:---|
| **DRY** | `config.py` — все константы в одном месте; `utils/math_helpers.py` — переиспользуемая математика |
| **KISS** | Простые классы, без ECS, без лишних абстракций |
| **SOLID (SRP)** | Каждый файл < 150 строк, одна ответственность |
| **SOLID (DIP)** | Model не импортирует pygame; алгоритмы — чистые функции |
| **Композиция > наследование** | `Creature` содержит `brain: SimplePerceptron`, а не наследуется от него |

## 🔬 Часть 3. Детальный разбор алгоритмов

### 🔴 1. Генетический алгоритм (×4)

**Где живёт:** `src/algorithms/ga.py` + `src/model/population.py`

**Что делает:** Эволюция популяции — отбор, скрещивание, мутация генов.

**Где вызывается:**
```
world.py → population.py → ga.py
   ↓              ↓            ↓
update()    evolve()    selection()
                           crossover()
                           mutate()
                           adaptive_rate()
```

**Связь с другими алгоритмами:**
- 🧬 Гены → **Перцептрон** (веса = гены)
- 🧬 Фитнес → **FSM** (сколько еды съел, сколько прожил)
- 🧬 **Tournament Selection** — часть ГА

**Ключевые функции:**
| Функция | Что делает |
|:---|:---|
| `tournament_selection(pop, k=3)` | Выбирает k случайных особей, берёт лучшую |
| `crossover(p1, p2)` | Смешивает гены двух родителей |
| `mutate(genome, rate)` | Случайно меняет гены |
| `adaptive_rate(pop)` | Динамически меняет `rate` на основе разнообразия генов |

---

### 🔴 2. Перцептрон (×4)

**Где живёт:** `src/algorithms/perceptron.py` + `src/model/creature.py`

**Что делает:** Принимает решение — в какое состояние перейти (SEEK/FLEE/WANDER).

**Где вызывается:**
```
creature.py → update()
    ↓
brain.compute(sensors) → decision
    ↓
if decision > 0.4:  state = SEEK
elif decision < -0.4:  state = FLEE
else:  state = WANDER
```

**Связь с другими алгоритмами:**
- 🧠 Веса перцептрона = **гены из ГА**
- 🧠 Выход перцептрона → **FSM** (выбор состояния)
- 🧠 Сенсоры: `food_signal`, `energy_signal` — данные из **Uniform Grid**

**Формула:**
```
output = tanh(w₁·x₁ + w₂·x₂ + ... + w₇·x₇ + bias)
```

---

### 🟡 3. Steering Behaviors (×2)

**Где живёт:** `src/algorithms/steering.py` + `src/model/creature.py`

**Что делает:** Плавное движение существ через векторные силы.

**Где вызывается:**
```
creature.py:
  _apply_steering() → steering.seek()      # для A* waypoints
  _apply_movement() → steering.seek()      # для SEEK без pathfinder
  _apply_movement() → steering.flee()      # (если активирован)
  _apply_movement() → steering.separation() # (если активирован)
```

**Связь с другими алгоритмами:**
- 🧭 `seek()` используется для движения к **waypoints от A***
- 🧭 `seek()` используется для преследования **партнёра в REPRODUCE**
- 🧭 Работает вместе с **FSM** — в каждом состоянии свои силы

**Главная формула (Рейнольдс, 1999):**
```
Steering = Desired_Velocity - Current_Velocity
```

---

### 🟡 4. Uniform Grid (×2)

**Где живёт:** `src/algorithms/spatial_grid.py` + `src/model/world.py`

**Что делает:** Делит мир на ячейки 50×50 для быстрого поиска соседей.

**Где вызывается:**
```
world.py → update():
    1. self.grid.clear()                    # Очистка
    2. for f in food: grid.insert(f, ...)   # Раскладываем еду
    3. for c in creatures: grid.insert(c, ...)  # Раскладываем существ
    4. nearby = grid.query_radius(...)      # Запрос соседей

creature.py → update():
    nearby = world.grid.query_radius((x, y), PERCEPTION_RADIUS)
```

**Связь с другими алгоритмами:**
- 🔍 Даёт список `nearby` для **перцептрона** (есть ли еда рядом)
- 🔍 Даёт `visible_food` для **A*** (к какой еде идти)
- 🔍 Даёт кандидатов для **Circle-Circle** (кого проверять на столкновение)
- 🔍 Даёт `nearby_creatures` для **REPRODUCE** (поиск партнёра)

---

### 🟢 5. FSM (×1)

**Где живёт:** `src/model/creature.py` (класс `State(Enum)`)

**Что делает:** Переключает состояния существа.

**Где вызывается:**
```
creature.py → update():
    if energy > 80: state = REPRODUCE
    else:
        decision = brain.compute(sensors)
        if decision > 0.4: state = SEEK
        elif decision < -0.4: state = FLEE
        else: state = WANDER
```

**Связь с другими алгоритмами:**
- 🔄 **Перцептрон** принимает решение о переходе
- 🔄 В каждом состоянии — своя логика:
  - `SEEK` → **A*** + **Steering**
  - `REPRODUCE` → **Steering** (seek к партнёру)
  - `WANDER` → случайное **Steering**
  - `FLEE` → случайное направление

---

### 🟢 6. A* Pathfinding (×1)

**Где живёт:** `src/algorithms/astar.py` + `src/model/creature.py`

**Что делает:** Ищет путь к еде, обходя препятствия.

**Где вызывается:**
```
creature.py → update() в состоянии SEEK:
    if dist_to_food > GRID_CELL_SIZE * 3:
        self.current_path = pathfinder.find_path(
            self.x, self.y,
            closest_food[0], closest_food[1]
        )
```

**Связь с другими алгоритмами:**
- 🗺️ Использует **Uniform Grid** для проверки препятствий (`world_to_grid`)
- 🗺️ Возвращает waypoints → **Steering** двигает существо по ним
- 🗺️ Работает только в состоянии **SEEK** (решение **FSM** + **перцептрон**)

---

### 🟢 7. Circle-Circle Collision (×1)

**Где живёт:** `utils/collision.py` + `src/model/world.py`

**Что делает:** Проверяет, съело ли существо еду.

**Где вызывается:**
```
world.py → _check_eating():
    nearby = grid.query_radius(...)  # Сначала через сетку
    for food in nearby:
        if check_circle_collision(creature, food):  # Потом точно
            creature.energy += food.energy
            self.food.remove(food)
```

**Связь с другими алгоритмами:**
- 🔍 **Uniform Grid** даёт кандидатов (быстрый фильтр)
- 🔍 **Circle-Circle** проверяет точное столкновение
- 🔍 Результат → энергия существа → влияет на **FSM** и **перцептрон**

**Формула:**
```
dist² ≤ (r₁ + r₂)²   ← без sqrt, быстро!
```

---

### 🟢 8. Tournament Selection (×1)

**Где живёт:** `src/algorithms/ga.py` → `tournament_selection()`

**Что делает:** Выбирает родителей для скрещивания.

**Где вызывается:**
```
population.py → evolve():
    for _ in range(new_pop_size):
        parent1 = tournament_selection(pop, k=3)
        parent2 = tournament_selection(pop, k=3)
        child = crossover(parent1, parent2)
        mutate(child)
```

**Связь с другими алгоритмами:**
- 🧬 Часть **Генетического алгоритма**
- 🧬 Выбранные родители → **кроссовер** → новые **гены** → **перцептрон**

### Как связаны алгоритмы между собой?
> *«Все алгоритмы работают как единая система. **ГА** эволюционирует гены, которые являются весами **перцептрона**. Перцептрон каждый кадр принимает решение о состоянии **FSM**. В зависимости от состояния, существо использует **A*** для навигации к еде и **Steering Behaviors** для плавного движения. **Uniform Grid** ускоряет поиск соседей и кандидатов для столкновений, которые точно проверяются через **Circle-Circle**. **Tournament Selection** — часть ГА для отбора родителей».
