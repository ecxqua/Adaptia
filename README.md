# 🧬 Adaptia

Алгоритмическая симуляция-наблюдение, где игрок исследует эволюцию популяций в динамической среде, стратегически управляя её параметрами.

## 📖 Основная идея
Игрок выступает в роли наблюдателя-экспериментатора. В среде с ограниченными ресурсами и препятствиями запускается популяция простых существ. Каждое существо обладает набором «генов», которые определяют его поведение и шансы на выживание.

Цель проекта — не «победить», а **исследовать**, как разные параметры среды и алгоритмы принятия решений влияют на эволюцию популяции. Адаптивный генетический алгоритм предотвращает вырождение, а простой перцептрон позволяет существам принимать контекстные решения.

Проект делает акцент на **алгоритмической прозрачности**, **детерминированной эволюции** и **интерактивной визуализации**, а не на контентной нагрузке.

## 🎮 Ключевые механики

| Механика | Описание |
|----------|----------|
| 🧬 **Адаптивная эволюция** | Гены существ мутируют и скрещиваются. Скорость мутации автоматически растёт, если популяция становится однородной — это предотвращает «застревание» эволюции. |
| 🧠 **Перцептрон для решений** | Существа принимают решения (`искать еду / бежать / блуждать`) через простой однослойный перцептрон с 7 входами и активацией `tanh`. Веса нейросети = гены, которые эволюционируют. |
| 💙 **Половое размножение** | Когда существо сыто (энергия > 80), оно переходит в состояние `REPRODUCE` и ищет партнёра. При столкновении двух «синих» существ создаётся потомок с генами от обоих родителей (кроссовер + мутация). |
| 🌀 **Плавное поведение (Steering)** | Движение строится на векторных силах: `seek` (к цели), `flee` (от опасности), `wander` (блуждание). Существ не «телепортируются», а плавно поворачивают и ускоряются. |
| 🗺️ **Интерактивная среда** | Игрок может в реальном времени добавлять еду (ЛКМ) или препятствия (ПКМ), менять параметры мира через ползунки и наблюдать реакцию популяции. |
| 📊 **Визуализация данных** | Графики фитнеса, гистограммы распределения генов, полноэкранный режим статистики, отладочные векторы сил — всё рисуется через `pygame.draw`. Никаких внешних библиотек для графиков. |
| 💾 **Экспорт и сохранение** | Конфигурации среды и популяции сохраняются в JSON (`F5`/`F9`), статистика поколений экспортируется в CSV (`C`) для последующего анализа. |

## 🕹️ Управление

| Клавиша / Действие | Функция |
|---|---|
| `ЛКМ` | Добавить еду в точке клика |
| `ПКМ` | Добавить препятствие (существо будет обходить его через A*) |
| `S` | Открыть/закрыть панель настроек (5 ползунков) |
| `ESC` | Пауза / продолжить / вернуться из статистики |
| `1` / `2` / `5` | Скорость симуляции ×1 / ×2 / ×5 |
| `G` | Показать/скрыть мини-графики в углу |
| `C` | Экспорт статистики в CSV |
| `F5` / `F9` | Сохранить / загрузить состояние игры в JSON |
| `M` | Включить/выключить фоновую музыку |

**Параметры среды (ползунки):**
- Скорость мутации (`MUTATION_RATE`)
- Сила мутации (`MUTATION_STRENGTH`)
- Плотность еды (`FOOD_SPAWN_RATE`)
- Расход энергии (`ENERGY_DECAY`)
- Длительность поколения (`GENERATION_TIME`)

## 🧠 Поведение существ (FSM)

Каждое существо имеет 4 состояния, визуализируемых цветом и формой:

| Состояние | Цвет | Форма | Триггер |
|---|---|---|---|
| `WANDER` | ⚪ Серый | Круг | Базовое блуждание, исследование среды |
| `SEEK` | 🟢 Зелёный | Треугольник | Перцептрон > 0.4 + есть еда в радиусе |
| `FLEE` | 🔴 Красный | Квадрат | Перцептрон < -0.4 (паника) |
| `REPRODUCE` | 🔵 Синий | Круг | Энергия > 80, ищет партнёра |

Переходы между состояниями определяются **перцептроном**, чьи веса эволюционируют через ГА.

## 🧮 Алгоритмическое ядро

Проект построен вокруг эволюционных вычислений и оптимизированных пространственных запросов. Ниже перечислены ключевые алгоритмы и источники для изучения.

| Уровень | Алгоритм | Суть | Источники |
|---|---|---|---|
| 🔴 Сложный (×4) | **Адаптивный генетический алгоритм** | Эволюция параметров популяции с динамической настройкой скорости мутации на основе дисперсии генов. Предотвращает преждевременную сходимость. | 🔗 [Mitchell, M. *An Introduction to Genetic Algorithms*](https://mitpress.mit.edu/books/introduction-genetic-algorithms) <br> 🔗 [Xetren: Генетические алгоритмы](https://gg.xetren.com/algorithms) |
| 🔴 Сложный (×4) | **Простой перцептрон (1 слой)** | Линейная комбинация 7 входов (энергия, еда, сенсоры) с весами → `tanh` → приоритет действия. Веса = гены, эволюционируют вместе с поведением. | 🔗 [3Blue1Brown: But what is a neural network?](https://www.3blue1brown.com/topics/neural-networks) <br> 🔗 [Wikipedia: Perceptron](https://en.wikipedia.org/wiki/Perceptron) |
| 🟡 Средний (×2) | **Steering Behaviors (Reynolds)** | Векторная сила для плавного движения `seek` (притяжение к цели) | 🔗 [Red3D: Steering Behaviors](https://www.red3d.com/cwr/steer/) <br> 🔗 [Game Programming Patterns: Behavioral AI](https://gameprogrammingpatterns.com/behavioral-ai.html) |
| 🟡 Средний (×2) | **Uniform Grid (Пространственное разбиение)** | Делит поле на фиксированные ячейки. Снижает сложность поиска соседей с `O(n²)` до `O(n)`, проверяя только объекты в соседних клетках. | 🔗 [Game Programming Patterns: Spatial Partition](https://gameprogrammingpatterns.com/spatial-partition.html) <br> 🔗 [Red Blob Games: Grids](https://www.redblobgames.com/grids/parts/) |
| 🟢 Лёгкий (×1) | **A\* Pathfinding** | Поиск кратчайшего пути по сетке с обходом препятствий. Эвристика — евклидово расстояние. Пересчитывается раз в секунду для оптимизации. | 🔗 [Red Blob Games: A* Introduction](https://www.redblobgames.com/pathfinding/a-star/introduction.html) <br> 🔗 [Xetren: A* Algorithm](https://gg.xetren.com/algorithms) |
| 🟢 Лёгкий (×1) | **Tournament Selection** | Отбор родителей для скрещивания: случайно выбираем `k` особей, оставляем наиболее приспособленную. Стабильнее и проще рулетки. | 🔗 [Wikipedia: Tournament selection](https://en.wikipedia.org/wiki/Tournament_selection) |
| 🟢 Лёгкий (×1) | **FSM (Конечный автомат)** | Переключение состояний: `WANDER → SEEK → FLEE → REPRODUCE`. Структурирует логику поведения без спагетти-кода. | 🔗 [Game Programming Patterns: State](https://gameprogrammingpatterns.com/state.html) |
| 🟢 Лёгкий (×1) | **Circle-Circle Collision** | Проверка поедания еды / столкновения существ через сравнение квадратов расстояний. Математически точный и быстрый способ. | 🔗 [Red Blob Games: Circle-Circle](https://www.redblobgames.com/grids/circle-drawing/) |

**Подсчёт баллов по рубрике:**
- Сложные: 2 × 4 = 8
- Средние: 2 × 2 = 4
- Лёгкие: 4 × 1 = 4
- **Итого: 16 → кап 15 баллов ✅**

## 🚀 Запуск

```bash
# 1. Клонировать репозиторий
git clone <repo-url>
cd Adaptia

# 2. Создать виртуальное окружение
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # Linux/Mac

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Запустить игру
python main.py

# 5. (Опционально) Запустить тесты
pytest tests/ -v
```

**Файл `requirements.txt`:**
```
pygame>=2.6.0
pytest>=8.0.0
```

**Опционально:** для фоновой музыки положите файл `music.mp3` или `music.ogg` в корень проекта.
