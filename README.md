# 🧬 Adaptia

Алгоритмическая симуляция-наблюдение, где игрок исследует эволюцию популяций в динамической среде, стратегически управляя её параметрами.

---

## 📖 Основная идея
Игрок выступает в роли наблюдателя-экспериментатора. В среде с ограниченными ресурсами и угрозами запускается популяция простых существ. Каждое существо обладает набором «генов» (скорость, зрение, агрессия, социальность), которые определяют его поведение и шансы на выживание.

Цель проекта — не «победить», а **исследовать**, как разные параметры среды и алгоритмы принятия решений влияют на эволюцию популяции. Адаптивный генетический алгоритм предотвращает вырождение, а простой перцептрон позволяет существам принимать контекстные решения.

Проект делает акцент на **алгоритмической прозрачности**, **детерминированной эволюции** и **интерактивной визуализации**, а не на контентной нагрузке.

---

## 🎮 Ключевые механики
| Механика | Описание |
|----------|----------|
| 🧬 Адаптивная эволюция | Гены существ мутируют и скрещиваются. Скорость мутации автоматически растёт, если популяция становится однородной — это предотвращает «застревание» эволюции. |
| 🧠 Перцептрон для решений | Существа принимают решения (`искать еду / бежать / размножаться`) через простой однослойный перцептрон. Веса нейросети = гены, которые эволюционируют. |
| 🌀 Плавное поведение (Steering) | Движение строится на векторных силах: `seek`, `flee`, `separation`, `alignment`. Существ не «телепортируются», а плавно поворачивают и ускоряются. |
| 🗺️ Интерактивная среда | Игрок может в реальном времени добавлять еду (ЛКМ) или опасности (ПКМ), менять параметры мира через ползунки и наблюдать реакцию популяции. |
| 📊 Визуализация данных | Графики среднего фитнеса, гистограммы распределения генов, отладочные векторы сил — всё рисуется через `pygame.draw`. Никаких внешних библиотек для графиков. |
| 💾 Экспорт и сохранение | Конфигурации среды и популяции сохраняются в JSON, статистика поколений экспортируется в CSV для последующего анализа. |

## 🛠 Стек технологий
- **Язык:** Python 3.10+
- **Движок:** Pygame 2.x (только стандартные модули)
- **Архитектура:** Model/View/Controller, Data-Driven (конфиги в JSON), фиксированный таймстеп
- **Вспомогательные модули:** `dataclasses`, `typing`, `collections`, `json`, `csv`, `math`, `random`
- **Инструменты разработки:** `pytest`, `flake8`, `black`, `git`
- **Сборка:** `pyinstaller` (опционально, для демонстрации)

## 🧮 Алгоритмическое ядро
Проект построен вокруг эволюционных вычислений и оптимизированных пространственных запросов. Ниже перечислены ключевые алгоритмы и источники для изучения.

| Алгоритм | Суть | Источники |
|----------|------|-----------|
| **Адаптивный генетический алгоритм** | Эволюция параметров популяции с динамической настройкой скорости мутации на основе дисперсии генов. Предотвращает преждевременную сходимость. | 🔗 [Mitchell, M. *An Introduction to Genetic Algorithms*](https://mitpress.mit.edu/books/introduction-genetic-algorithms) <br> 🔗 [Xetren: Генетические алгоритмы](https://gg.xetren.com/algorithms) |
| **Простой перцептрон (1 слой)** | Линейная комбинация входов (энергия, опасность, еда) с весами → функция активации → приоритет действия. Веса = гены, эволюционируют вместе с поведением. | 🔗 [3Blue1Brown: But what is a neural network?](https://www.3blue1brown.com/topics/neural-networks) <br> 🔗 [Wikipedia: Perceptron](https://en.wikipedia.org/wiki/Perceptron) |
| **Steering Behaviors (Reynolds)** | Векторные силы для плавного движения: `seek` (притяжение к цели), `flee` (отталкивание от угрозы), `separation` (избегание толпы). | 🔗 [Red3D: Steering Behaviors](https://www.red3d.com/cwr/steer/) <br> 🔗 [Game Programming Patterns: Behavioral AI](https://gameprogrammingpatterns.com/behavioral-ai.html) |
| **Uniform Grid (Пространственное разбиение)** | Делит поле на фиксированные ячейки. Снижает сложность поиска соседей с `O(n²)` до `O(n)`, проверяя только объекты в соседних клетках. | 🔗 [Game Programming Patterns: Spatial Partition](https://gameprogrammingpatterns.com/spatial-partition.html) <br> 🔗 [Red Blob Games: Grids](https://www.redblobgames.com/grids/parts/) |
| **A\* Pathfinding** | Поиск кратчайшего пути по сетке с обходом препятствий. Эвристика — манхэттенское расстояние. Обновляется раз в N кадров для оптимизации. | 🔗 [Red Blob Games: A* Introduction](https://www.redblobgames.com/pathfinding/a-star/introduction.html) <br> 🔗 [Xetren: A* Algorithm](https://gg.xetren.com/algorithms) |
| **Tournament Selection** | Отбор родителей для скрещивания: случайно выбираем `k` особей, оставляем наиболее приспособленную. Стабильнее и проще рулетки. | 🔗 [Wikipedia: Tournament selection](https://en.wikipedia.org/wiki/Tournament_selection) |
